# مساري | Masari - نظام وتطبيق الحجوزات والسفر المتكامل

تطبيق ويب عربي متكامل لحجز تذاكر الطيران، الفنادق، والمستشفيات، مبني بالكامل باستخدام تقنيات الويب القياسية:
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**

---

## 🌟 مميزات المشروع

- **تصميم عربي أصيل 100% RTL:** متناسق مع أفضل المعايير البصرية المستوحاة من الهوية المعتمدة (الأخضر الداكن، الأبيض، البيج، والرمادي).
- **11 واجهة متكاملة ومستقلة:**
  1. `index.html` - واجهة البداية (Welcome)
  2. `login.html` - واجهة تسجيل الدخول (Login)
  3. `register.html` - واجهة إنشاء حساب جديد (Register)
  4. `home.html` - الصفحة الرئيسية (Home)
  5. `flights.html` - واجهة البحث عن الرحلات الجوية (Flights Search)
  6. `flight-details.html` - واجهة تفاصيل الرحلة (Flight Details)
  7. `hotels.html` - واجهة الفنادق والمنتجعات (Hotels)
  8. `hospitals.html` - واجهة المستشفيات والرعاية الصحية (Hospitals)
  9. `bookings.html` - واجهة سجل الحجوزات (My Bookings)
  10. `payment.html` - واجهة الدفع وإتمام الحجز (Payment)
  11. `confirmation.html` - واجهة تأكيد الحجز بنجاح (Confirmation)
- **شريط تحكم متقدم للمعاينة:**
  - زر التبديل إلى «عرض الجوال» (محاكاة الهاتف الذكي 1:1 كما في الصورة المرجعية).
  - زر التبديل إلى «الشاشة الموسعة» (عرض سطح مكتب احترافي متجاوب).
  - قائمة تنقل فوري بين كافة الصفحات.
- **تفاعل كامل مع LocalStorage:**
  - تسجيل الدخول والإنشاء مع التحقق الفعلي من صحة المدخلات.
  - محرك بحث ديناميكي عن الرحلات والفنادق والمستشفيات.
  - دورة حجز متكاملة من الاختيار حتى الدفع والتأكيد وحفظ التذكرة في سجل الحجوزات.
  - إمكانية استعراض تفاصيل التذكرة والباركود وإلغاء الحجز الفعلي.

## 🚀 النشر على Vercel

المشروع جاهز للنشر الفوري على Vercel عبر ملف الإعداد `vercel.json`:
- يدعم `cleanUrls` للروابط النظيفة.
- يدعم التوجيه السلس بين الصفحات الثابتة.

## 👨‍💻 التطوير والتشغيل المحلي

يمكن فتح أي صفحة مباشرة في المتصفح أو تشغيل خادم محلي:
```bash
npx serve .
```
أو عبر بايثون:
```bash
python -m http.server 8000
```

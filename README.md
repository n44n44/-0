# منصة غيم سبيس (Ghaym Space) ☁️🛒
### سوق الحرفيين والأسر المنتجة في حضرموت واليمن

منصة تجارة إلكترونية متكاملة ومتعددة التجار (Multi-Vendor Marketplace) مصممة ومطورة خصيصاً لخدمة السوق اليمني ومحافظة حضرموت (المكلا)، بتصميم مطابق حرفياً (Pixel-Perfect) للهوية البصرية والشعار المعتمد.

---

## 🎨 الهوية البصرية ونظام التصميم (Design System)

* **الكحلي العميق (Primary Navy):** `#172A46` (للأشرطة العلوية، الفوتر، العناوين، والبطاقات).
* **الأزرق السماوي (Brand Sky):** `#54B9F2` (للأزرار التفاعلية، الروابط، شارات التوثيق، والمؤشرات).
* **الخلفية الثلجية (Ice Background):** `#F3F6FB` (خلفية نظيفة ومريحة للعين).
* **الخط المعتمد:** خط **`IBM Plex Sans Arabic`** مطبق بالكامل باتجاه القراءة العربي (**RTL**).

---

## 🧭 الهيكلية والملاحة الثابتة (Navigation Order)

القائمة العلوية الثابتة مرتبة حرفياً حسب المتطلبات:
> **الشعار ⬅️ الرئيسية ⬅️ التصنيفات ⬅️ المنتجات ⬅️ جميع المتاجر ⬅️ من نحن**

* **محدد الموقع الجغرافي:** "اليمن / حضرموت والمكلا" مع دعم لأحياء المكلا (حي الورد، فوة، الديس، الشرج، الغويزي، فلك، بويش، روكب) ومدن حضرموت (سيئون، الشحر، تريم).
* **محرك البحث الذكي:** يقدم اقتراحات فورية للمنتجات الحرفية والمتاجر أثناء الكتابة.

## 📱 دليل الواجهات المنفذة والمميزات

### 1. الواجهة الرئيسية (Home Page)
* **بانر العروض:** عروض غيم سبيس لدعم الحرفيين والأسر المنتجة، خصومات تصل إلى 50%، زر ذهبي تفاعلي، ومجسم عربة الغيم المتوهجة.
* **دوائر التصنيفات:** ديكور وهدايا، صناعات يدوية (فخار)، ملابس وأزياء، أسر منتجة، مشغولات تراثية، حلويات ومخبوزات.
* **المتاجر المميزة لهذا الأسبوع:** متجر غيم الهدايا والديكور، بخور وعطور المكلا، والفرع الذهبي، وسمر المكلا مع شارة التوثيق.
* **بانر دعوة التجار:** "هل لديك موهبة أو مشروع منزلي؟ انضم إلى غيم سبيس الآن وابدأ البيع مجاناً!".
* **أحدث المنتجات:** حقائب يمنية، مباخر تقليدية، شموع معطرة، وتحف كونكريت بسعر 24,000 ر.ي.

### 2. واجهة جميع المتاجر (All Stores Page)
* فلاتر التصنيف: الأعلى تقييماً، المتاجر الموثقة، المضافة حديثاً، الأقرب إليك.
* شبكة للمتاجر مع عدد المنتجات وزيارة المتجر وإضافة سريعة.
* شريط التصفية الجانبي حسب النطاق الجغرافي ونوع النشاط.

### 3. واجهة سلة التسوق (Shopping Cart)
* تفصيل المنتجات والكميات بالريال اليمني (YER).
* حاسبة الشحن الجغرافي بالكيلومترات ورسوم التوصيل لأحياء المكلا.
* كوبونات الخصم الفوري وتنبيه شرط الدفع عند الاستلام.

### 4. واجهة إتمام الطلب والدفع (Checkout)
* تكامل كامل مع بوابات الدفع المحلية في اليمن:
  1. **الكريمي إكسبرس (كريمي جوال):** رقم الحساب `3029182741` مع حقل إشعار الحوالة.
  2. **شركة العمقي وإخوانه للصرافة:** رقم الحساب `254189033`.
  3. **بنك القطيبي الإسلامي (محفظة بنكي):** رقم الحساب `110294819`.
  4. **شركة بن دول للصرافة:** رقم الحساب `99201481`.
  5. **الدفع عند الاستلام (COD):** مفعل فقط للطلبات التي تزيد قيمتها عن 20,000 ريال يمني.
* إطلاق احتفال Confetti عند إتمام الطلب والتحويل للتتبع.

### 5. واجهة تتبع الطلبات والشحن الجغرافي (Order Tracking)
* شريط تقدم الحالة المباشر المكون من 5 مراحل.
* خريطة تفاعلية لمدينة المكلا وحساب المسافة المتبقية بالكيلومترات (2.1 كم) والوقت (8 دقائق).
* بطاقة مندوب التوصيل المعتمد (أحمد محمد) مع أزرار الاتصال والواتساب وكود الأمان (OTP: 4829).

### 6. لوحة تحكم التاجر المستقلة (Merchant Dashboard)
* **إدارة المنتجات:** جدول بالمخزون والأسعار وإضافة المنتجات يدوياً.
* **مساعد الذكاء الاصطناعي (AI Product Generator ✨):** كتابة اسم المنتج ليقوم الـ AI تلقائياً بصياغة العنوان والوصف التسويقي واقتراح السعر والتصنيف.
* **إدارة الطلبات:** متابعة الحالات وتحديثها وتسليمها للمندوب.
* **معاينة المتجر بتصميم حي (Live Preview):** معاينة حية لشكل المتجر أمام الزوار.

### 7. بوابة المندوب وتوصيل الطلبات (Courier Dashboard)
* **حالة الاتصال الفورية:** شارة "متصل الآن 🟢" ومؤشرات الإنجاز (5 مهام قادمة، 12 تم التوصيل، 98% معدل الالتزام، +50 إجمالي التوصيلات).
* **خريطة المسار الحي (Live Route Map):** خريطة تفاعلية توضح موقع المندوب في المكلا (شارع الميناء ➔ حي الورد) مع عداد المسافة (2.4 كم) والوقت المتبقي (8 دقائق).
* **بطاقة الطلبية القادمة للتوصيل (#1047):** عرض صورة المنتج، العنوان الدقيق، رسوم التوصيل (1,200 YER)، وزر "بدء التوصيل 🛵" التفاعلي.
* **إشعارات وتأكيدات التسليم الفورية.**

### 8. لوحة تحكم المشرف العام (Admin Dashboard / Super Admin)
* إحصائيات المنصة الكلية (إجمالي المبيعات، العمولات، المتاجر النشطة).
* إدارة المتاجر الموثقة ومنح أو إلغاء التوثيق.
* إدارة العمولات وتسوية المستحقات المالية.
* ضبط إعدادات السوق ونطاق الكيلومترات للتوصيل.

### 9. الفوتر المتطابق (Footer)
* المنحنى الموجي السحابي العلوي وتوهج الغيوم ثلاثية الأبعاد.
* روابط سريعة، خدمة العملاء، صندوق الاشتراك البريدي، وروابط التواصل الاجتماعي الخمس.

## 🚀 طرق التشغيل والمعاينة

1. **التشغيل المباشر الفوري (بنقرة واحدة دون خادم):**
   انقر مرتين على ملف:
   📁 **`index.html`**
   *(الملف مدمج ومستقل بالكامل ويعمل محلياً دون أي أخطاء أو قيود)*

2. **عبر ملف التشغيل السريع:**
   📁 **`تشغيل_الموقع.bat`**

3. **عبر خادم التطوير (Vite Dev Server):**
   ```bash
   npm run dev
   ```
   ثم افتح: `http://localhost:5173/`
